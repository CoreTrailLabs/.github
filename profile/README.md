## CoreTrailKit

**Less guessing. More knowing.**

A desktop app for watching local services and investigating changes across repositories. Connect a project, start a watch, and inspect service state, health checks, alarms and event history.

[Download CTK](https://coretrailkit.com/download) · [Product & getting started](https://github.com/CoreTrailLabs/CoreTrailKit) · [Runnable examples](https://github.com/CoreTrailLabs/ctk-examples) · [Watch real walkthroughs](https://coretrailkit.com/resources)

Available for macOS on Apple Silicon. Download without signing in; sign in inside the app. CTK's application source is private. Our example code is public and MIT-licensed.
